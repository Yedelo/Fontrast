Adds numerous ways to customize the look of text

## Dependencies

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [YetAnotherConfigLib (YACL)](https://modrinth.com/mod/yacl)
- [Mod Menu](https://modrinth.com/mod/modmenu) to reach the config screen (please do it)

## Features

<details><summary>Text Style Control</summary>

- Bold Control
- Italic Control
- Strikethrough Control
- Underline Control
- Obfuscation Control

</details>

<details><summary>Text Color Control</summary>

- Multiply Colors
- Shadow Scale
- Custom Text Colors
- Custom Shadow Colors

</details>

<details><summary>Advanced</summary>

- Shadow Offset Multiplier
- Bold Offset Multiplier

</details>
